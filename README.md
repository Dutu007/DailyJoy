# DailyJoy 🌱
## 你的治愈系日常心情打卡助手

一个简单、美观的移动端 Web 应用，帮助你记录每一天的心情、完成日常习惯打卡、管理待办事项，并且看着你的小森林一天一天茁壮成长！

## ✨ 功能特性

### 🌳 每日心情记录
- 5种精选心情供你选择：开心、平静、焦虑、难过、生气
- 不同心情对应不同颜色的成长树，让每一天都有色彩
- 心情日历查看，回顾你的情绪变化

### 📝 习惯打卡
- 预设3个基础习惯：喝水8杯、阅读30分钟、早起
- 支持添加自定义习惯
- 多种打卡频率设置：每天、每周、按间隔天数
- 习惯完成率影响成长树的茂密程度

### 🌲 我的森林
- 每日记录生成独特的成长树
- 月度森林视图，查看你的成长历程
- 心情分布统计，更了解自己
- 精美动画效果，视觉治愈体验

### 📅 日程管理
- 日历视图查看和添加日程
- 待办事项完成标记
- 轻松管理每一天的安排

## 🛠️ 技术栈

- **前端框架**：Vue 3 (Vue Composition API)
- **样式**：Tailwind CSS
- **画布渲染**：原生 Canvas
- **后端存储**：
  - Supabase（云端存储，支持多端同步）
  - LocalStorage（本地降级存储）
- **图标**：Phosphor Icons

## 🚀 快速开始

### 本地运行

直接在浏览器中打开 `index.html` 文件即可运行！

```bash
# 或者使用 Python 简单启动一个本地服务器
python3 -m http.server 8000

# 然后在浏览器访问：http://localhost:8000
```

### 环境变量

如果你想配置自己的 Supabase 后端，需要修改 [js/db.js](file:///workspace/js/db.js#L3-L4) 中的配置：

```javascript
const SUPABASE_URL = 'your-supabase-url';
const SUPABASE_KEY = 'your-supabase-anon-key';
```

## 📖 使用指南

### 1. 注册/登录
- 首次使用时，输入邮箱和密码进行注册
- 已注册用户可直接登录
- 没有配置 Supabase 时也可以使用，数据会保存在本地

### 2. 记录心情
- 在首页选择今天的心情
- 选择后会立即同步保存

### 3. 习惯打卡
- 点击习惯卡片完成打卡
- 点击「添加新习惯」创建你自己的习惯
- 配置习惯的打卡频率

### 4. 查看森林
- 切换到「树洞」标签页
- 查看今日之树和我的森林
- 点击左右箭头切换月份

### 5. 心情日历
- 切换到「日历」标签页
- 查看每一天的心情记录
- 点击日期写下小日记

### 6. 管理日程
- 切换到「日程」标签页
- 添加新的待办事项
- 点击圆圈标记任务完成
